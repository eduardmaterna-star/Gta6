# District Run — browser prototype

A small, self-contained, playable 2D open-world driving prototype. It uses only HTML Canvas and plain JavaScript; there are no downloads, plugins, or Unreal Engine requirements.

## Play

After GitHub Pages deployment, open the repository's **Settings → Pages** site URL. The workflow in `.github/workflows/browser-demo-pages.yml` publishes this folder when changes land on `main`.

For local play, open `index.html` in a current desktop browser.

## Controls

- **W A S D**: walk; steer and accelerate while in the car
- **E**: enter or exit the nearby car
- **Space**: handbrake
- **P**: pause

Collect all four packages and reach the green exit. Police pursue you after each pickup.

This is an original early prototype, not GTA VI or an official Rockstar product. The Unreal Engine C++ project remains a separate development path.
