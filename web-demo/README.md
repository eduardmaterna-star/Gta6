# District Run — 3D browser test build

A small playable 3D city-driving prototype made with Three.js. It runs in a current desktop browser and does not require Unreal Engine. The visual style is an original neon coastal city inspired by modern open-world games; it does not use GTA VI assets.

## Play

Open `index.html` in a current desktop browser. An internet connection is needed to load the pinned Three.js library.

## Controls

- **W A S D**: walk; steer and accelerate while driving
- **E**: enter or leave the nearby car
- **Space**: handbrake
- **P**: pause
- **Drag mouse**: rotate camera
- **Mouse wheel**: zoom
- **R**: recover the car while driving

Collect four packages and reach the green exit. Police pursue you after pickups.

This is a browser test prototype, not a finished commercial game, installer, or official Rockstar product.
