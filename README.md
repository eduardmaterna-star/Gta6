# GTA6 — originální open-world projekt

Pracovní název projektu. Jde o samostatnou originální hru v Unreal Engine 5 zasazenou do fiktivní herní verze Prahy; nejde o oficiální produkt Rockstar Games.

## Milestone 001 — hratelný městský blockout

- C++ third-person pohyb a kamera
- procedurálně sestavené městské bloky, silnice, chodníky a park
- základ pro další rozšiřování mapy

Viz `Docs/MILESTONE_001.md` a `Docs/MILESTONE_002_CITY_MAP.md`.

## Požadavky

- Unreal Engine 5 (kompatibilní verze)
- Visual Studio 2022 s workloadem **Desktop development with C++** a **Game development with C++**

Otevři `OPEN_WORLD_Next_Gen.uproject`, nech Unreal vygenerovat IDE soubory a projekt zkompiluj.

> Stav: zdrojový prototyp. Projekt nebyl v tomto prostředí zkompilován v Unreal Engine.
