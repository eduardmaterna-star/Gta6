## Important technical boundary
World Partition is not enabled merely by writing an INI setting. The current greybox is generated by a runtime actor and is not an editor-authored World Partition map. A real World Partition `.umap` must be created and saved inside Unreal Editor. This milestone documents that required editor operation instead of pretending a text-file change created a streamed world.

## Civilian AI foundation (repository implementation)

A first lightweight civilian character prototype is available at
`Source/OpenWorldNextGen/AI/OWCivilianCharacter.*`.

- Uses Unreal's built-in AIController and Navigation System.
- Chooses random reachable NavMesh destinations around its current location.
- Uses timers rather than a per-frame actor tick.
- Rejects destinations too close to produce meaningful visible movement.
- Enables Unreal CharacterMovement's basic RVO local avoidance; this is not a full crowd simulation.
- Retries safely if AI possession or navigation data is not ready.
- Clears its timer and stops movement when the actor ends play.
- Uses a temporary cube proxy until original character meshes and animations exist.

### Editor setup and current limits

To test it, place a `NavMeshBoundsVolume` over a walkable test area, build navigation,
then place one or more `AOWCivilianCharacter` actors inside the bounds. The current
greybox district does not yet include a configured NavMesh volume, so the class is
not automatically spawned and no civilian population is claimed to be playable.

This is basic wandering only. It does not implement traffic, crowd avoidance,
perception, schedules, dialogue, police, combat, or mission behavior. Unreal C++
compilation and in-editor behavior still require UE 5.8 on Windows.


## Reproducible greybox variation

The runtime district now exposes an editor-default `GenerationSeed`. Building counts and dimensions are generated from one `FRandomStream` initialized with that seed, so a given seed produces a repeatable layout while changing the seed produces a different blockout. This remains a small single-actor greybox generator; it is not World Partition, a road graph, or a production city-generation system.


## Configurable greybox footprint

The runtime greybox now exposes `DistrictCellCount` and `DistrictCellSize` as editor defaults.
The cell count is clamped to 2–12 and the cell size to 80–300 metres, both in editor metadata
and again at runtime. This allows controlled prototype-size experiments while keeping the
single-actor generator bounded. It does not provide world streaming or production-scale city
generation; larger worlds still require editor-authored World Partition cells and profiling.

Building footprints and their row spacing scale with the selected cell size, so the smaller
supported district presets do not retain the original 180-metre block offsets. The seeded
random stream still controls building counts and dimensions within that scaled layout.
